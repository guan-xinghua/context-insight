# insight — 会话洞察 · 观测（Observe）

CANNBot-Relay 的会话级可观测包：回答"运行中发生了什么"，把 Agent 会话黑盒变白盒。

- **全量画像**：Token · 成本 · 上下文
- **时间线**：Turn / Tool / Skill 可回放
- **取证**：按时间戳重建文件现场

**迁入来源**：[cannbot-skills](https://gitcode.com/cann/cannbot-skills) `plugins-community/cannbot-insight` 主体代码（Web UI、CLI/TUI、导入与分析流水线）。

**状态**：待迁入。包内代码、测试与使用文档将在迁移后提供。

安装（迁入后）：根目录 `./install.sh insight` 或本目录 `./install.sh`。
